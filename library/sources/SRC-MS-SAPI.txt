## Examples

The following example is part of a console application that initializes a
[SpeechSynthesizer](system.speech.synthesis.speechsynthesizer?view=net-11.0-pp) object and speaks a string.

    
    
    using System;
    using System.Speech.Synthesis;
    
    namespace SampleSynthesis
    {
      class Program
      {
        static void Main(string[] args)
        {
    
          // Initialize a new instance of the SpeechSynthesizer.
          SpeechSynthesizer synth = new SpeechSynthesizer();
    
          // Configure the audio output.
          synth.SetOutputToDefaultAudioDevice();
    
          // Speak a string.
          synth.Speak("This example demonstrates a basic use of Speech Synthesizer");
    
          Console.WriteLine();
          Console.WriteLine("Press any key to exit...");
          Console.ReadKey();
        }
      }
    }
    

## Remarks

When you create a new [SpeechSynthesizer](system.speech.synthesis.speechsynthesizer?view=net-11.0-pp) object,
it uses the default system voice. To configure the
[SpeechSynthesizer](system.speech.synthesis.speechsynthesizer?view=net-11.0-pp) to use one of the installed
speech synthesis (text-to-speech) voices, use the
[SelectVoice](system.speech.synthesis.speechsynthesizer.selectvoice?view=net-11.0-pp) or
[SelectVoiceByHints](system.speech.synthesis.speechsynthesizer.selectvoicebyhints?view=net-11.0-pp) method. To
get information about which voices are installed, use the
[GetInstalledVoices](system.speech.synthesis.speechsynthesizer.getinstalledvoices?view=net-11.0-pp) method and
the [VoiceInfo](system.speech.synthesis.voiceinfo?view=net-11.0-pp) class.

This class also provides control over the following aspects of speech synthesis:

  * To configure the output for the [SpeechSynthesizer](system.speech.synthesis.speechsynthesizer?view=net-11.0-pp) object, use the [SetOutputToAudioStream](system.speech.synthesis.speechsynthesizer.setoutputtoaudiostream?view=net-11.0-pp), [SetOutputToDefaultAudioDevice](system.speech.synthesis.speechsynthesizer.setoutputtodefaultaudiodevice?view=net-11.0-pp), [SetOutputToNull](system.speech.synthesis.speechsynthesizer.setoutputtonull?view=net-11.0-pp), and [SetOutputToWaveFile](system.speech.synthesis.speechsynthesizer.setoutputtowavefile?view=net-11.0-pp) methods.

  * To generate speech, use the [Speak](system.speech.synthesis.speechsynthesizer.speak?view=net-11.0-pp), [SpeakAsync](system.speech.synthesis.speechsynthesizer.speakasync?view=net-11.0-pp), [SpeakSsml](system.speech.synthesis.speechsynthesizer.speakssml?view=net-11.0-pp), or [SpeakSsmlAsync](system.speech.synthesis.speechsynthesizer.speakssmlasync?view=net-11.0-pp) method. The [SpeechSynthesizer](system.speech.synthesis.speechsynthesizer?view=net-11.0-pp) can produce speech from text, a [Prompt](system.speech.synthesis.prompt?view=net-11.0-pp) or [PromptBuilder](system.speech.synthesis.promptbuilder?view=net-11.0-pp) object, or from [Speech Synthesis Markup Language (SSML) Version 1.0](https://go.microsoft.com/fwlink/?LinkId=201763).

  * To pause and resume speech synthesis, use the [Pause](system.speech.synthesis.speechsynthesizer.pause?view=net-11.0-pp) and [Resume](system.speech.synthesis.speechsynthesizer.resume?view=net-11.0-pp) methods.

  * To add or remove lexicons, use the [AddLexicon](system.speech.synthesis.speechsynthesizer.addlexicon?view=net-11.0-pp) and [RemoveLexicon](system.speech.synthesis.speechsynthesizer.removelexicon?view=net-11.0-pp) methods. The [SpeechSynthesizer](system.speech.synthesis.speechsynthesizer?view=net-11.0-pp) can use one or more lexicons to guide its pronunciation of words.

  * To modify the delivery of speech output, use the [Rate](system.speech.synthesis.speechsynthesizer.rate?view=net-11.0-pp) and [Volume](system.speech.synthesis.speechsynthesizer.volume?view=net-11.0-pp) properties.

The [SpeechSynthesizer](system.speech.synthesis.speechsynthesizer?view=net-11.0-pp) raises events when it
encounters certain features in prompts:
([BookmarkReached](system.speech.synthesis.speechsynthesizer.bookmarkreached?view=net-11.0-pp#system-speech-
synthesis-speechsynthesizer-bookmarkreached),
[PhonemeReached](system.speech.synthesis.speechsynthesizer.phonemereached?view=net-11.0-pp#system-speech-
synthesis-speechsynthesizer-phonemereached),
[VisemeReached](system.speech.synthesis.speechsynthesizer.visemereached?view=net-11.0-pp#system-speech-
synthesis-speechsynthesizer-visemereached), and
[SpeakProgress](system.speech.synthesis.speechsynthesizer.speakprogress?view=net-11.0-pp#system-speech-
synthesis-speechsynthesizer-speakprogress)). It also raises events that report on the start
([SpeakStarted](system.speech.synthesis.speechsynthesizer.speakstarted?view=net-11.0-pp#system-speech-
synthesis-speechsynthesizer-speakstarted)) and end
([SpeakCompleted](system.speech.synthesis.speechsynthesizer.speakcompleted?view=net-11.0-pp#system-speech-
synthesis-speechsynthesizer-speakcompleted)) of speak operations and on the change of the speaking voice
([VoiceChange](system.speech.synthesis.speechsynthesizer.voicechange?view=net-11.0-pp#system-speech-synthesis-
speechsynthesizer-voicechange)).

Note

Always call [Dispose](system.speech.synthesis.speechsynthesizer.dispose?view=net-11.0-pp) before you release
your last reference to the [SpeechSynthesizer](system.speech.synthesis.speechsynthesizer?view=net-11.0-pp).
Otherwise, the resources it is using will not be freed until the garbage collector calls the
[SpeechSynthesizer](system.speech.synthesis.speechsynthesizer?view=net-11.0-pp) object's
[Finalize](system.object.finalize?view=net-11.0-pp) method.
