**The NVIDIA GB200 NVL72 by HPE is a rack-scale system optimized to accelerate large AI model training, fine-
tuning, and real-time inferencing for AI models over 1 trillion parameters.**

This architecture is comprised of 36 NVIDIA Grace ARM processors and 72 NVIDIA Blackwell GPUs all
interconnected with NVIDIA’s 5th-gen NVLink technology. The rack is powered by a set of power shelves through
a bus bar and the compute trays are cooled with cold plates that are mounted on the CPUs and GPUs.

###

Overview

**NVIDIA GB200 NVL72 by HPE**

The HPE offering incorporates direct liquid cooling technologies from HPE. NVIDIA GB200 NVL72 by HPE offers a
complete, scalable solution for AI & HPC customers everywhere. NVIDIA GB200 NVL72 by HPE provides maximum
performance for Large Model AI Training and Deep Learning. Built with high-speed networking technologies,
integrated storage, a robust software portfolio and management tools, NVIDIA GB200 NVL72 by HPE systems enable
customers to innovate and prepare for tomorrow’s challenges.

#### Power Delivery and Requirements

The NVL72 rack is powered by a set of 6 (max: 8) power shelves and a DC bus bar. Each power shelf is fed by a
power whip with input connector type IEC 60309 5-wire 560P6W. Each power shelf can provide up to 33 kW of
power to the rack.

  

The rack’s TDP (thermal design power) is 132 kW nominal with a EDPp (electrical design power – peak) of 1.5x
TDP or approximately 192 kW

  

HPE suggests that data centers should provision their bus ways to be able to support 192 kW EDPp.

1 Power Shelf contains

  * – 6x 5.5 kW PSU – Power Supply Units

  * – 1x PMC – Power shelf management controller

  * – 1x Power Shelf Chassis

  

#### CDU (Cooling Distribution Unit) for NVIDIA GB200 NVL72 by HPE

  

The cooling distribution unit (CDU) is a liquid-to-liquid heat exchanger that is used to remove heat from HPE
GB200 NVL72 by HPE.

  

The CDU uses a secondary loop to circulate a heat transfer liquid to the cold plates. The heat captured in the
secondary loop is transferred to the facilities primary loop via a liquid-to-liquid heat exchanger. The CDU is
designed to circulate and control the heat transfer fluid to the manifolds that are in each rack.

  

The in-row CDU is rated for 1.3 MW of cooling. One CDU supports a maximum of 8 racks.

HPE supports overhead (top feed) and underfloor (bottom feed) secondary loop configurations. A spacer manifold
can be used for racks that do not need liquid cooling.

#### HPE Server UEFI

Unified Extensible Firmware Interface (UEFI) is an industry standard that provides better manageability and
more secured configuration than the legacy ROM while interacting with your server at boot time.

  

**UEFI enables numerous new capabilities:**

  * – Secure Boot enabled for enhanced security

  * – Embedded UEFI Shell

  * – USB 3.0 Stack

  

**Capabilities**

  * – TPM 2.0 Support

  * – iSCSI Software Initiator Support.

  * – NVMe Boot Support.

  * – HTTP/HTTPs Boot support as a PXE alternative.

  * – Platform Trust Technology (PTT) can be enabled.

  * – Boot support for option cards that only support a UEFI option ROM.

  * – PXE Support

  * – UEFI (Unified Extensible Firmware Interface Forum) 2.6

  * – USB 2.0 Compliant

  * – USB 3.0 Compliant

#### Security

  * – UEFI Secure Boot.

  * – NIST SP800-147B Protect, Detect, Recover for BIOS Tamper-free updates – components digitally signed and verified using CNSA strength RSA4096 signing key.

  * – Secure Recovery – recover critical firmware to known good state on detection of compromised firmware. Event recorded in the event log.

  * – UEFI TPM 2.0 (Trusted Platform Module 2.0) - supports OpenSSL 3.0 provide for secure remote connectivity session to system.

  * – Support for multiple Redfish role-based access control (RBAC) accounts ensuring that passwords need not be shared and can provide separation of duties.
